# The Self-Checkout Is Judging You

A single funny line in the voice of a smug, judgmental self-checkout machine:
the shopper bought nine energy drinks and one banana, then asked for a bag —
so the machine charged them for the bag, the judgment, and the two minutes
it spent approving its own receipt.

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`.
